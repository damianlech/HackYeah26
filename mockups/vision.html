Mandate

Agents get mandates, not keys.

A self-hosted AI control layer. Every agent→LLM and agent→MCP call passes one policy brain that redacts, blocks, budgets and audits it, and the exfiltration guarantee still holds when every AI detector is switched off.

canonical spec design/VISION-SPEC.md code namespace aicl 6 Python devs · ~24 h P0 ≈ 79.5 of 81 person-hours · plan (a) ~54 h runs offline on Apple Silicon

What the judges score

Six formal requirements: a central policy, deterministic and AI guardrails, budgets for paid and local models, historical-exploit signatures from an external feed, reporting for two audiences, and a self-testing suite. Judges type their own prompts, edit our config live and run our tests.

Robustness & quality of guardrails30%
Architecture & performance20%
Security reporting20%
Self-testing suite15–20%
Practicality & scalability10–15%

The two task PDFs disagree on the last two weights (CRITERIA 15/15, RULES 20/10). Ask the organizers at H0. Either way, testing is worth 15–20%, so it can't be left to the last hours.

Three pillars

Five independent designs were scored by three judge personas. These pillars are what the canonical spec kept.

01

Authority beats detection

Detectors produce evidence. Deterministic authority produces the guarantee: data may only go where the user's task, the policy or a trusted tool says. Chat content never mints authority.

Judge disables every AI detector and hijacks the agent. The email to audit@evil.test is still denied.
02

Evidence is computed

Posture, OWASP/ATLAS coverage, self-test status and latency come from what the gateways actually loaded, never from a hand-typed number.

Judge edits policy.yaml: 2/2 replicas apply it in under 2 s, posture drops, the self-test shows GAP.
03

It ships and survives poking

Hermetic make test, make demo-offline with no model and no Wi-Fi, and the demo storyline itself runs as a test.

A mentor runs make test alone and gets a green control × case matrix in about 2 minutes.

Data plane

Two stateless FastAPI replicas behind Caddy. OpenAI-compatible /v1/chat/completions, filtered /v1/models, /v1/me, /v1/runs, and /mcp/{server}. Python, because Go was only ~1.5× cheaper per stream in our bench.

Control plane

A separate control service on an admin network: report API over DuckDB, SSE, live self-test, posture, signed audit checkpoints, Playground. If it dies, enforcement continues.

Hybrid detection cascade

Cheap first, expensive only when needed. The most restrictive verdict wins and detectors can only add restrictions. Semantic failures fail to taint, never open. Budgets are targets until re-measured on the demo Mac at H2.

T0 · policy
≤ 2 ms

authN, run token, kill switch, model allowlist, parameter hygiene, budget reserve

T1 · deterministic
≤ 5 ms

multi-view normaliser, PII checksums, secrets, RE2 signatures, tool validators, destination provenance

T2 · semantic
≤ 120 ms

multilingual injection classifier in sliding windows + exemplar kNN (EN+PL)

T3 · guard LLM (P1)
≤ 1.5 s

llama-guard3:1b in parallel with the upstream call, gating the first token

OUT · stream
≤ 150 ms

trigger-aware holdback: links, secrets, digit runs, canary. Never a TCP reset.

The guarantee: destination provenance

Every destination an agent writes to (email, URL host, IBAN) is classified by where it came from. Membership is a set lookup over canonical values, so paraphrasing and laundering gain nothing. Balanced profile, external sinks:

Destination came fromClean runTainted runTainted + private data read
User task (/v1/runs) or policy allowlistallowallow + flagask
A trusted_source tool (e.g. CRM)allowallow + flagask
Unknownaskaskdeny · trifecta
Seen only in untrusted content (web page, tool result)denydenydeny
Homoglyph spoof of a trusted destinationdeny + criticaldeny + criticaldeny + critical

Until human approvals (C23) land in P1, ask returns a block with "approval required". Run tokens are HMAC-signed by the gateway and minted only with a user credential. A forged or missing token falls into a sticky fallback run that keeps its taint.

Limits: what Mandate will not do

The residual threat register (spec §14.2, T1-T18) is the closing slide. A security team should trust a control layer that states its limits.

Residual threats

  • T1 Harmful-but-allowed actions: we govern actions, not truthfulness.
  • T2 Low-bandwidth exfiltration inside an allowed channel.
  • T3 Confused deputy through a CRM record the attacker controls.
  • T5 Unmanaged host agents: the fence covers containerised agents only.
  • T6 Adaptive attacks on classifiers: detectors are evidence only.
  • T13 Chat-only jailbreak while the guard is down (balanced profile).
  • T16 agent→agent is thin (P1); ASI07 partial.

Not built, simulated or unmeasured

  • Not built at P0: Squid, live Keycloak/LDAP, the A2A proxy, the Anthropic dialect (so Claude Code is not governed live), approvals, OCSF export, the HF scanning mirror.
  • Paid APIs are simulated (sim/*, labelled "simulated commercial pricing").
  • Local compute is wall clock at P0 (T15); native Ollama durations are P1.
  • Polish detection quality is unmeasured until make eval (P1).
